## Environment Variables

### Required Variables

#### Shopify Configuration

```bash
# Shopify Shop Details
SHOPIFY_SHOP_URL=hearnshobbies.myshopify.com
# The myshopify.com domain of your store

SHOPIFY_ACCESS_TOKEN=shpat_xxxxxxxxxxxxxxxxxxxxx
# Admin API access token (obtained after OAuth or from Settings → Apps)

# Shopify App Credentials (for OAuth)
SHOPIFY_APP_API_KEY=xxxxxxxxxxxxxxxx
# API key from Shopify Partner Dashboard → Apps → Your App

SHOPIFY_APP_API_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# API secret key from Shopify Partner Dashboard

SHOPIFY_APP_REDIRECT_URI=https://your-app.railway.app/shopify/callback
# OAuth callback URL (must match Shopify app settings)
```

#### Anthropic API

```bash
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# Claude API key from console.anthropic.com
```

#### Database Configuration

```bash
DATABASE_URL=postgresql://user:password@host:5432/database
# Full PostgreSQL connection string (Railway provides this)

DATABASE_USERNAME=postgres
# Database username (usually 'postgres')

DATABASE_PASSWORD=xxxxxxxxxxxxx
# Database password (generated by Railway)
```

## Shopify App Configuration

### App Settings (Shopify Partner Dashboard)

```yaml
App name: AI Search Assistant
App URL: https://your-app.railway.app
Allowed redirection URL(s):
  - https://your-app.railway.app/shopify/callback

Admin API access scopes:
  - read_products          # Search products
  - read_orders           # (Optional) Order history
  - write_script_tags     # Theme extension
```

### OAuth Scopes Explanation

| Scope | Purpose | Required? |
|-------|---------|-----------|
| `read_products` | Search and display products | Yes |
| `write_script_tags` | Inject theme extension | Yes |
| `read_orders` | Show order history (future) | No |
| `read_customers` | Personalization (future) | No |

## CORS Configuration

### WebConfig.java

```java
@Configuration
public class WebConfig {

    @Value("${cors.allowed.origins:https://hearnshobbies.com}")
    private String[] allowedOrigins;

    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {
            @Override
            public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/api/**")
                    .allowedOrigins(allowedOrigins)
                    .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                    .allowedHeaders("*")
                    .allowCredentials(true)
                    .maxAge(3600);
            }
        };
    }
}
```

### API Configuration

**File:** `/frontend/src/services/api.js`

```javascript
import axios from 'axios'

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || '/api',
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json'
  }
})

// Request interceptor (add auth token if needed)
api.interceptors.request.use(
  (config) => {
    // Add authorization header if needed
    return config
  },
  (error) => {
    return Promise.reject(error)
  }
)

// Response interceptor (handle errors globally)
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      // Handle unauthorized
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)

export default api
```

## Security Configuration

### HTTPS Enforcement (Production)

```yaml
server:
  ssl:
    enabled: false  # Railway handles SSL termination

# Enforce HTTPS in production
management:
  server:
    ssl:
      enabled: false
```

### Secret Management

**DO NOT commit:**
- API keys
- Database passwords
- OAuth secrets
- Access tokens

**Use environment variables:**
- Railway: Dashboard → Variables
- Development: `.env` file (gitignored)
- Production: Secure environment variable storage
